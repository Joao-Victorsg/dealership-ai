# Data Model: Sales API

**Phase**: 1 — Design  
**Branch**: `001-sales-api`  
**Date**: 2026-04-19

---

## Entity Overview

The Sales API owns a single primary table: `sales`. There are no foreign keys
to external services — client and car data are stored as JSONB snapshots,
preserving point-in-time accuracy regardless of changes in originating services.

---

## Database Schema

### Table: `sales`

```sql
-- V1__create_sales_table.sql
CREATE TABLE IF NOT EXISTS sales (
    id               UUID           NOT NULL,
    car_id           UUID           NOT NULL,
    client_id        UUID           NOT NULL,
    sale_value       NUMERIC(19, 4) NOT NULL,
    registered_at    TIMESTAMPTZ    NOT NULL DEFAULT NOW(),
    client_snapshot  JSONB          NOT NULL,
    car_snapshot     JSONB          NOT NULL,

    CONSTRAINT pk_sales          PRIMARY KEY (id),
    CONSTRAINT uk_sales_car_id   UNIQUE (car_id),
    CONSTRAINT chk_sales_value   CHECK (sale_value > 0)
);

-- Index for client-scoped list queries (FR-009)
CREATE INDEX idx_sales_client_id ON sales (client_id);

-- Index for date-range filter queries (FR-009, FR-010)
CREATE INDEX idx_sales_registered_at ON sales (registered_at);

-- Composite index for staff queries filtering by both client and date
CREATE INDEX idx_sales_client_registered ON sales (client_id, registered_at);
```

### Column Definitions

| Column | Type | Constraints | Notes |
|--------|------|-------------|-------|
| `id` | `UUID` | PK, NOT NULL | UUID v4 generated by service (FR-007) |
| `car_id` | `UUID` | NOT NULL, UNIQUE | Enforces at-most-one-sale-per-car (FR-017) |
| `client_id` | `UUID` | NOT NULL | Keycloak subject ID of the buyer |
| `sale_value` | `NUMERIC(19,4)` | NOT NULL, > 0 | Car listed value × 1.10 (FR-002) |
| `registered_at` | `TIMESTAMPTZ` | NOT NULL, DEFAULT NOW() | UTC; set by DB, not application (FR-008) |
| `client_snapshot` | `JSONB` | NOT NULL | Point-in-time client data at sale time |
| `car_snapshot` | `JSONB` | NOT NULL | Point-in-time car data at sale time |

**Notes:**
- No `updated_at` column — sales are append-only (FR-013, Article VIII)
- No `deleted_at` / soft-delete column — sales are never deleted (FR-014)
- `registered_at` has `DEFAULT NOW()` at DB level; Hibernate must not override this.
  Use `@Column(insertable = false)` and rely on DB default, or set in service via `Instant.now()`.

## Java Entity: `Sale`

**File**: `domain/entity/Sale.java`

```java
@Entity
@Table(
    name = "sales",
    uniqueConstraints = @UniqueConstraint(name = "uk_sales_car_id", columnNames = "car_id")
)
@NoArgsConstructor(access = AccessLevel.PROTECTED)   // Hibernate only
@AllArgsConstructor(access = AccessLevel.PRIVATE)    // Builder only
@Builder
public class Sale {

    @Id
    @Column(nullable = false, updatable = false)
    private UUID id;

    @Column(name = "car_id", nullable = false, updatable = false)
    private UUID carId;

    @Column(name = "client_id", nullable = false, updatable = false)
    private UUID clientId;

    @Column(name = "sale_value", nullable = false, precision = 19, scale = 4, updatable = false)
    private BigDecimal saleValue;

    @Column(name = "registered_at", nullable = false, updatable = false)
    private Instant registeredAt;

    @JdbcTypeCode(SqlTypes.JSON)
    @Column(name = "client_snapshot", nullable = false, updatable = false,
            columnDefinition = "jsonb")
    private ClientSnapshot clientSnapshot;

    @JdbcTypeCode(SqlTypes.JSON)
    @Column(name = "car_snapshot", nullable = false, updatable = false,
            columnDefinition = "jsonb")
    private CarSnapshot carSnapshot;

    // Read-only accessors — no setters
    public UUID getId()                   { return id; }
    public UUID getCarId()                { return carId; }
    public UUID getClientId()             { return clientId; }
    public BigDecimal getSaleValue()      { return saleValue; }
    public Instant getRegisteredAt()      { return registeredAt; }
    public ClientSnapshot getClientSnapshot() { return clientSnapshot; }
    public CarSnapshot getCarSnapshot()   { return carSnapshot; }
}
```

## DTO: Request

### `RegisterSaleRequest` (self-validating record)

**File**: `dto/request/RegisterSaleRequest.java`

The compact constructor normalizes data and throws `IllegalArgumentException`
for structural violations (→ 400). Business rule violations (car status, ownership)
are checked in the service layer (→ 422 / 403).

```java
public record RegisterSaleRequest(
    @NotNull  UUID   carId,
    @NotNull  UUID   clientId,
    @Valid    @NotNull ClientSnapshotRequest clientSnapshot,
    @Valid    @NotNull CarSnapshotRequest    carSnapshot
) {
    public RegisterSaleRequest {
        // Structural cross-field checks (400-level)
        if (carId != null && clientId != null && carId.equals(clientId)) {
            throw new IllegalArgumentException("carId and clientId must be different");
        }
    }
}
```

**Nested request records:**

```java
public record ClientSnapshotRequest(
    @NotBlank String firstName,
    @NotBlank String lastName,
    @NotBlank @Pattern(regexp = "\\d{3}\\.\\d{3}\\.\\d{3}-\\d{2}") String cpf,
    @NotBlank @Email String email,
    @Valid @NotNull AddressSnapshotRequest address
) {}

public record AddressSnapshotRequest(
    @NotBlank String street,
    @NotBlank String number,
    String complement,         // optional
    @NotBlank String neighborhood,
    @NotBlank String city,
    @NotBlank @Size(min = 2, max = 2) String state,
    @NotBlank String postcode
) {}

public record CarSnapshotRequest(
    @NotBlank String model,
    @NotNull  @Min(1886) @Max(2100) Integer manufacturingYear,
    @NotBlank String manufacturer,
    @NotBlank String externalColor,
    @NotBlank String internalColor,
    List<String> optionalItems,
    @NotBlank String type,
    @NotBlank String category,
    @NotBlank @Pattern(regexp = "[A-HJ-NPR-Z0-9]{17}") String vin,
    @NotNull  @DecimalMin("0.01") BigDecimal listedValue,
    @NotNull  CarStatus status
) {
    public CarSnapshotRequest {
        optionalItems = optionalItems != null ? List.copyOf(optionalItems) : List.of();
        // Normalize VIN to uppercase
        if (vin != null) vin = vin.toUpperCase();
    }
}
```

## DTO: Response

### `SaleResponse` record

**File**: `dto/response/SaleResponse.java`

```java
@Builder
public record SaleResponse(
    @Schema(description = "Unique sale identifier (UUID v4)")
    UUID id,
    @Schema(description = "Identifier of the car sold")
    UUID carId,
    @Schema(description = "Identifier of the client buyer")
    UUID clientId,
    @Schema(description = "Final sale value including 10% tax", example = "49500.00")
    BigDecimal saleValue,
    @Schema(description = "Timestamp of sale registration (UTC)")
    Instant registeredAt,
    @Schema(description = "Client details at time of purchase")
    ClientSnapshotResponse clientSnapshot,
    @Schema(description = "Car details at time of purchase")
    CarSnapshotResponse carSnapshot
) {
    public static SaleResponse from(Sale sale) {
        return SaleResponse.builder()
            .id(sale.getId())
            .carId(sale.getCarId())
            .clientId(sale.getClientId())
            .saleValue(sale.getSaleValue())
            .registeredAt(sale.getRegisteredAt())
            .clientSnapshot(ClientSnapshotResponse.from(sale.getClientSnapshot()))
            .carSnapshot(CarSnapshotResponse.from(sale.getCarSnapshot()))
            .build();
    }
}
```

| Exception | HTTP Status | Trigger |
|-----------|-------------|---------|
| `CarNotAvailableException` | 422 | Car status in snapshot is not AVAILABLE |

| `SaleNotFoundException` | 404 | No sale found for the given ID |
| `SnsPublishException` | 503 | SNS publish fails after all retries / CB open |

## Repository: `SaleRepository`

**File**: `repository/SaleRepository.java`

```java
public interface SaleRepository extends JpaRepository<Sale, UUID> {

    // US2: Client's own sales with optional date range filter
    Page<Sale> findByClientId(UUID clientId, Pageable pageable);

    Page<Sale> findByClientIdAndRegisteredAtBetween(
        UUID clientId, Instant from, Instant to, Pageable pageable);

    // US3: Staff queries — all optional filter combinations handled by Specification
    // (Spring Data JPA Specification or @Query)
}
```

Staff list queries with multiple optional filters (clientId, carId, dateFrom, dateTo)
are implemented using **Spring Data JPA `Specification<Sale>`** to avoid
combinatorial method explosion.

## State Transitions

```
Sale does not exist
        │
        ▼
    REGISTERED (persisted + SNS published)
        │
        └── FINAL (immutable, never deleted)
```

There is a single valid state transition: from non-existent to REGISTERED.
No updates, no deletion, no state machine beyond creation.

## Indexes and Performance Notes

| Index | Columns | Purpose |
|-------|---------|---------|
| `pk_sales` | `id` | Primary key lookup (`GET /sales/{id}`) |
| `uk_sales_car_id` | `car_id` | Unique constraint enforcement (FR-017) |
| `idx_sales_client_id` | `client_id` | Client's own sales list (US2) |
| `idx_sales_registered_at` | `registered_at` | Date-range filter (US2, US3) |
| `idx_sales_client_registered` | `client_id, registered_at` | Combined filter for US2 with date range |

The `car_id` unique index also enables fast staff filter-by-car queries (US3, at most 1 result).
JSONB `client_snapshot` and `car_snapshot` are not indexed — queries never filter on snapshot fields.
